# Security

Please do not report security vulnerabilities through public GitHub Issues.

When the repository becomes public, use GitHub private vulnerability reporting
when available, or another private maintainer contact published by the project.

Do not include credentials, access tokens, private endpoints, household
identifiers, provider payloads or other sensitive deployment data in reports.

Bifröst treats discovery and authorization as separate concerns. Discovering a
compatible endpoint must never grant access to a Butler runtime.
