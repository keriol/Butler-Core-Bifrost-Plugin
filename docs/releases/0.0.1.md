# Bifröst 0.0.1

First Public Alpha checkpoint of the reusable external/client bridge.

## Included

- framework-neutral HTTP ingress adapter;
- request correlation and structured transport errors;
- text request/response transport;
- optional explicit Butler target metadata;
- source Butler identity propagation;
- safe speaker/session metadata;
- read-only Butler directory transport;
- composed Bifröst/Core/Butler node manifest;
- DNS-SD service convention with credential-free public metadata;
- neutral synchronous client-notification descriptors.

## Live proving

The 0.0.1 line was proven through the canonical client path with preserved
correlation and observable READ -> ACTION -> READ/VERIFY behavior before this
release checkpoint.

## Deliberately deferred

- client pairing/enrollment and device credentials;
- structured interactive confirmations/continuations;
- proactive client notification delivery;
- concrete host authentication/policy implementation.

## Boundary

Bifröst transports client protocol data. It does not own Butler routing policy,
runtime behavior, household configuration, secrets or provider-specific logic.
