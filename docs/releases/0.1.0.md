# Bifröst 0.1.0 — Ignition

First minor release of the reusable external/client bridge and a component of
Ignition Phase 1 / IGNITION-001.

## Included

- framework-neutral HTTP ingress adapter;
- request correlation and structured transport errors;
- text request/response transport;
- optional explicit Butler target metadata;
- source Butler identity propagation;
- safe speaker/session metadata;
- read-only Butler directory transport;
- composed node-manifest surface;
- DNS-SD discovery convention with credential-free metadata;
- neutral synchronous client-notification descriptors.

## Ignition role

```text
Interphone 0.1.0 -> Bifröst 0.1.0 -> Midgard 0.1.0
```

Bifröst transports client protocol data and routing metadata. It does not own
Butler routing policy, household configuration or concrete runtime behavior.

## Deferred

- pairing/enrollment and device credentials;
- proactive client delivery;
- structured interactive continuations;
- concrete host authentication policy.
